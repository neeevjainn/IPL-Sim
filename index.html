📋 Google Sheets Setup Guide
1. Create a Google Sheet with these exact column headers in row 1:
id | name | nation | role | batting_style | bowling_type | batting_rating | bowling_rating | form | base_price | lot | six_hitter
2. role must be one of: BAT, WK, WK-BAT, AR, ALL, BOWL, PACE, SPIN
3. bowling_type: PACE, FAST, FAST-MEDIUM, MEDIUM, SPIN, LEG-SPIN, OFF-SPIN, ← for non-bowlers
4. lot: Put a lot number (1, 2, 3...) so players are grouped into auction lots
5. six_hitter: 1 if player is a big-hitter, 0 otherwise
6. batting_rating and bowling_rating: 40–99 scale
7. Go to File → Share → Publish to Web → CSV → Copy link
8. Paste the link above and click Load Players
